Support

Setup and support

Guidance for account setup, sync modes and safer HTML mail.

1

Add a Gmail account

Inlyra Mail currently uses a Gmail app password instead of your normal Gmail password.

  1. Open Google Account Security
    Google Account Security
  2. Turn on 2-Step Verification
    Google requires this before an app password can be created.
  3. Create an app password
    Open App passwords, enter “Inlyra Mail” as the app name, and create it.
  4. Enter it in Inlyra Mail
    Use your Gmail address as the email address and the generated 16-character app password in the password field. Spaces shown by Google can be ignored.
If App passwords is not available
Some work or school accounts, Advanced Protection configurations and certain security setups hide this option. Check your administrator’s policy or wait for Gmail OAuth support.
2

Choose a sync mode

Use IMAP IDLE for real-time waiting when supported by the provider, periodic sync for servers without IDLE, or Off for manual refresh only.

3

View HTML mail safely

External images and scripts are restricted by default. Allow images only for senders you trust, and check links before opening them.

4

Connection troubleshooting

Recheck the host, port, security mode and authentication method. Never send your password or app password in a support request.

Reporting an issue

Public channel: GitHub Issues
Use GitHub Issues for bug reports, feature requests and usage questions. Public issues are visible to other users, so replies are not guaranteed for every post.

When reporting a problem, prepare the following details so it can be investigated efficiently.

  • app version, Android version and device model
  • the screen and exact steps that reproduce the issue
  • how often it happens and the full error message
When sharing a screenshot or log
Hide email addresses, server names, passwords, app passwords, message bodies, attachments and other private information first. If possible, attach the diagnostic log created from “Settings → Sync status → Share diagnostic log” after checking its contents.

No separate private support channel is provided. Comments or messages on services such as note or OFUSE are not official support channels; important, specific posts may receive a reply when noticed, but replies are not guaranteed. Spam, promotion and posts containing sensitive information will not be handled.
